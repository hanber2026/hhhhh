## 3. 启动顺序与命令

单机：

```bash
mongod --config /etc/mongod-single.conf
```

副本集（三台依次）：

```bash
mongod --config /etc/mongod-rs.conf
# 仅在主节点执行一次初始化
mongosh "mongodb://127.0.0.1:27017" /data/scripts/rs_init.js
```

分片集群（严格按“配置服务器 → 分片 → mongos”顺序）：

```bash
# 三台：配置服务器
mongod --config /etc/mongod-cfg.conf
# 任意一台执行一次
mongosh --port 27019 /data/scripts/csrs_init.js
# nosql01、nosql02：分片
mongod --config /etc/mongod-shard.conf
# nosql03：路由
mongos --config /etc/mongos.conf
# 任选一台连 mongos 执行（addShard 必须用副本集主机名）
mongosh --port 27020 /data/scripts/shard_init.js
```

> 顺序颠倒会持续报 `FailedToSatisfyReadPreference ... for set csrs`；`addShard` 用 IP 会报 `host ... does not belong to replicaset`，必须写 `shard1/nosql01:27018`。

## 4. 认证配置

- 副本集/分片集群使用 keyFile 内部认证：`openssl rand -base64 756 > /data/mongodb/rs/keyfile`，**由一台生成后 scp 分发到其余节点**，三台 md5 必须一致（本环境为 `941eba1b6f530cf364026b02d76b9e8e`），权限 400，属主 mongod。
- 各配置文件末尾追加：

```yaml
security:
  authorization: enabled
```

> 追加前确认文件以换行结尾，否则会拼到上一行导致 `yaml-cpp: illegal map value`。

- 账号在 mongos（或副本集主节点）上用 localhost exception 创建：`lib_admin`（root@admin）、`librarian_rw`（readWrite@library_db）、`reader_ro`（read@library_db）。

```bash
  python3 -m tools.import_data --drop
```

## 6. 备份与导出

```bash
mongodump --uri='mongodb://lib_admin:Admin%40123@192.168.121.136:27020/?authSource=admin' \
  --db=library_db --out=/data/backup/dump-20261110
tar czf /data/backup/library_db-dump-20261110.tar.gz -C /data/backup dump-20261110

mongoexport --uri='...' --db=library_db --collection=category_stats --jsonArray --out=/data/export/category_stats.json
mongoexport --uri='...' --db=library_db --collection=category_stats --type=csv \
  --fields=category,book_count,stock_total,avg_price,avg_rating --out=/data/export/category_stats.csv
```

> CSV 已加 UTF-8 BOM，避免 Excel 直接打开时中文乱码。

## 7. 常用运维命令

```bash
# 副本集状态 / 读取偏好
mdbA --eval 'rs.status().members.forEach(m => print(m.name + " " + m.stateStr))'
bash /data/scripts/rs_readpref.sh

# 分片分布与查询路由
sdb /data/scripts/shard_topo.js
sdb /data/scripts/shard_query.js

# 索引
mdb /data/scripts/idx_create.js
mdb /data/scripts/idx_after.js
```

其中 `/usr/local/bin/mdb` 以 librarian_rw 连副本集，`/usr/local/bin/mdbA` 以 lib_admin 连副本集，`/usr/local/bin/sdb` 以 lib_admin 连 nosql03 的 mongos。
